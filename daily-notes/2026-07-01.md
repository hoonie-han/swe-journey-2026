## What I Learned Today

### Responsive Background

- `background-repeat: no-repeat;` — don't tile the image
- `background-position: center;` — anchor the image at the center
- `background-size: contain;` — keep the whole image visible at its original ratio
- `background-size: cover;` — fills the container; scales responsively as the window grows/shrinks, anchored from the center
- Shorthand (all in one line): `background: center/cover no-repeat;`
- `background-attachment: fixed;` behaves like `cover` for filling, but the image stays fixed in place while scrolling.

**Why the `/` between `center/cover`?**
- Because only `background-position` and `background-size` are paired together with a `/`.
- (`position/size`)

**Why no `/` after `cover`?**
- Because after `cover`, the other properties (like `no-repeat`) begin — they aren't part of the position/size pair.

### Transform

- `transform` can do many things: size, position, rotation, skew, etc.
- You can combine them in one line:
  - `transform: translate(100px, 100px) scale(2) rotate(15deg);`
- Most commonly used: `rotate`, `translate`, `scale`.

### Transition

- Write `transition` on the base state (`.box`), not on hover.
- That way the animation applies both on hover-in and hover-out.
- If you write `transition` on `.box:hover`, the transition only exists in the hover state — so it animates on mouse-over but snaps back instantly on mouse-out.
- Target specific properties:
  - `transition: background-color;` → animates only when the color changes
  - `transition: border-radius;` → animates only when the shape changes
  - `transition: all;` → animates everything
- Customize animation speed/easing curve here: https://cubic-bezier.com

## What I Learned Today

### Keyframes

Using `@keyframes` in CSS lets you build more detailed animations.

First define the keyframes and give the animation a name (e.g. `slidein`):

```css
@keyframes slidein {
  0% {
    border-radius: 0%;
    background-color: aquamarine;
  }
  50% {
    background-color: pink;
  }
  100% {
    border-radius: 100%;
    background-color: hotpink;
  }
}
```

Then, inside the element you want to animate, call the animation you defined:

```css
.box {
  width: 100px;
  height: 100px;
  margin: 20px;
  background-color: chocolate;
  animation: 3s infinite alternate slidein;
}
```

- `infinite` keeps the animation running continuously.
- `alternate` makes it run forward then backward (0% → 50% → 100% → 50% → 0% ...) so the start and end connect smoothly in a cycle.

**Timing functions:**
- `linear` = constant speed
- `ease` = default; starts and ends smoothly
- `ease-in` = starts slow, speeds up
- `ease-out` = starts fast, ends slow
- `ease-in-out` = slow start, fast middle, slow end

**Iteration / direction:**
- `infinite` = repeat forever
- `alternate` = go forward, then reverse back
- `infinite alternate` = keep going back and forth

### CSS Variables

Instead of finding and setting each element one by one, you can use `:root` to manage everything centrally.

```css
:root {
  --background-color: darkslategrey;
  --text-color: whitesmoke;
}
.first-list {
  background-color: var(--background-color);
  color: var(--text-color);
  margin-left: 8px;
}
.second-list {
  background-color: var(--background-color);
  color: var(--text-color);
  margin-left: 16px;
}
@media screen and (max-width: 768px) {
  :root {
    --background-color: darkslateblue;
    --text-color: white;
  }
}
```

- `:root` = variable storage
- `--background-color` = variable name
- `darkslategrey` = the value stored in the variable
- `var()` = function that pulls out a variable's value
- `var(--background-color)` = "get the value of `--background-color`"

**Changing variables in responsive design:**
- When the screen goes below 768px, the variable values change.
- So every element using `var(--background-color)` updates its color automatically.

**Key points:**
- `:root` = create the variables
- `var()` = use the variables
- `:root` inside `@media` = change variable values based on a condition
- If you don't use `var()`, the variable value won't apply

### HTML Data Attributes

`data-*` is used to store any custom data you want inside an HTML element.

Basic form:

```html
<div data-name="value"></div>
```

Example:

```html
<div data-display-name="donghoon">hoonie!!</div>
```

Meaning: create a `display-name` piece of data inside this `div` and store `donghoon` as its value.

`data-index`, `data-display-name` are not fixed names — they're names I make up as needed.

```html
<div data-index="1" data-display-name="donghoon"></div>
```

- `data-index="1"` = stores 1 as the index value
- `data-display-name="donghoon"` = stores donghoon as the display-name value

Use only what you need:

```html
<button data-product-id="27">Add to Cart</button>
<button data-price="49">Add to Cart</button>
```

**Selecting by data value in CSS:**

```css
div[data-display-name="donghoon"] {
  background-color: beige;
}
```

Meaning: select only the `div` whose `data-display-name` value is `donghoon` and apply the style.

**Reading data values in JavaScript with `dataset`:**

```js
const donghoonDiv = document.querySelector('div[data-display-name="donghoon"]');
console.log(donghoonDiv.dataset.displayName); // donghoon
```

**Important conversion rule:**

In HTML: `data-display-name`
In JavaScript: `dataset.displayName`

The hyphen `-` disappears and the next word's first letter becomes uppercase (camelCase).

Other examples:
- `data-user-id` → `dataset.userId`
- `data-product-price` → `dataset.productPrice`

**Key summary:**
- `data-*` = store custom data on an HTML element
- `data-index`, `data-display-name` = names I make up
- Only create the data you need
- CSS: select with `[data-name="value"]`
- JS: read with `element.dataset.name`

## Important

The difference between `@keyframes` and `animation`:
As an analogy — `@keyframes` is the dance-move instruction sheet, and `animation` is the command that tells the person to actually perform that dance.
